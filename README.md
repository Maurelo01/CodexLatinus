# Codex Latinus

Un compilador con interfaz gráfica desarrollado en Java y ANTLR4 que analiza, valida y traduce código del lenguaje *Codex Latinus* a *Pig Latin*. 

Proyecto desarrollado para el curso de Compiladores 2.
Mauricio Joel Gómez Barrios - 202031478

## Requisitos:
* **Java:** JDK 21 o superior.
* **Maven:** Para la compilación y gestión de dependencias.
* **Graphviz:** Obligatorio para renderizar el AST y la Tabla de Símbolos (`sudo apt install graphviz` en Linux).

## Cómo Ejecutar

## Opción 1: Usar el ejecutable (Recomendado)
Ubicarse en la raíz de la entrega y ejecuta el archivo `.jar` compilado:
```bash
java -jar Ejecutable/CodexLatinus-1.0-SNAPSHOT-jar-with-dependencies.jar
```
## Opción 2: hacer doble click en:
```bash
CodexLatinus-1.0-SNAPSHOT-jar-with-dependencies.jar
```
